# NETGUARD (static demo)

A front-end-only demo of the NETGUARD internet monitoring system. It uses sample data
and a fake login, saved in the browser (localStorage). It does not connect to the real
database or the Python monitor.

Demo logins: admin/demo, technician/demo, customer/demo

## Publish on GitHub Pages
1. Create a new public repository on GitHub.
2. Upload all files from this folder to the repository root (index.html must be at the top level).
3. Go to Settings > Pages. Under "Build and deployment", set Source to "Deploy from a branch",
   Branch to "main" and folder to "/ (root)", then Save.
4. After about a minute your link appears: https://YOUR-USERNAME.github.io/REPO-NAME/
